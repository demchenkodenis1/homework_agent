# Домашнее задание 1. Агент уровня 1 для AgentScore

Все домашние задания курса сдаются на [planerverse.ru](https://planerverse.ru/) — бенчмарк кодовых агентов. Платформа запускает вашего агента на задачах, он правит код, а оценивается итоговый `git diff`.

**Уровень 1:** агент проходит демо-проверку платформы — исправляет простую функцию на Python. Без инструментов и цикла: один запрос к модели. Всё нужное было на занятии 1.1: контекст, промпт, формат ответа, вызов модели из кода.

## Как платформа запускает агента

- Код агента лежит в `/agent` (только чтение), рабочая папка — `/testbed`, это git-репозиторий.
- Команда из `agent.json`: `python /agent/agent.py --task-file /task/TASK.md --workspace /testbed`.
- Модель и ключ — только из окружения: `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL`. Модель на платформе одна для всех: `deepseek-v4.1-flash`. Не записывайте адрес, ключ и имя модели в код.
- Поддерживаются Responses API и Chat Completions. Нельзя: `previous_response_id`, серверная история, встроенные инструменты сервиса. Историю, если она нужна, ведёт ваша программа.
- Ограничения: 600 секунд на задачу, 4096 выходных токенов на один запрос, без сети кроме модели.
- Агент работает без вопросов к человеку и завершается сам. Пустой diff — 0 баллов.
- Демо-проверка идёт в окружении Python 3.11 с `openai 2.26.0`. Поэтому в `pyproject.toml` и `uv.lock` зафиксирован `openai==2.26.0`.

Точные правила — в инструкции на сайте (ссылка «Инструкция агентам» на главной). Если правила на сайте и здесь расходятся, верны правила сайта.

## Что сделать

1. Создайте публичный репозиторий на GitHub из этой папки.
2. Допишите в `agent.py` места с пометкой TODO:
   - **TODO 1** — инструкции: задача, правила, формат ответа, из которого программа надёжно достанет путь и новое содержимое файла;
   - **TODO 2** — `build_context`: задача и файлы проекта в разделителях, без `.git` и огромных файлов;
   - **TODO 3** — `parse_files`: разбор ответа по вашему формату;
   - **TODO 4** (по желанию) — повторный запрос, если ответ не разобрался.
3. Проверьте локально (ниже).
4. Сделайте коммит, отправьте форму на сайте с адресом репозитория и полным SHA коммита и нажмите «Проверить демо».

Для сдачи нужны `agent.json`, `uv.lock` и README в корне репозитория — они уже есть.

## Локальная проверка

```bash
uv sync                    # или: pip install openai==2.26.0
cp .env.example .env       # впишите свой ключ OpenAI
uv run python local_check/run_check.py   # или python local_check/run_check.py после pip install
```

Скрипт делает то же, что демо: копирует пример из `local_check/sample/repo` во временный git-репозиторий, запускает агента командой платформы, печатает `git diff` и прогоняет скрытые тесты, которых агент не видел. В конце — «задача решена» или «задача не решена».

Локально вы работаете со своей моделью OpenAI, на платформе будет `deepseek-v4.1-flash`. Промпт, который работает с одной моделью, стоит проверить и на другой — вспомните показ 3 с занятия.

## Что будет дальше

Уровень 1 передаёт модели весь маленький проект одним запросом и принимает файлы целиком. На задачах бенчмарка из реальных репозиториев так не получится: проект не помещается во вход, а файл — в 4096 выходных токенов. На занятии 1.2 агент получит инструменты — искать и читать файлы, запускать тесты, править код по частям — и будет работать в цикле.
